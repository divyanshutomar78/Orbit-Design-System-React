# @orbit/tokens

Token CSS lives in the workspace `Orbit-Personal-Tokens` package. Import theme + platform bundles in your app:

```css
@import '../../Orbit-Personal-Tokens/dist/css/themes/d-green/index.css';
@import '../../Orbit-Personal-Tokens/dist/css/platforms/web/variables.css';
```

Available themes: `d-green`, `d-grey`, `n-green`, `n-grey`, `n-blue`.
